Privacy

Downly keeps download data local

Downly does not run a hosted service and does not upload your download history, file names, source URLs, or files. The extension works inside your Chrome profile using local browser APIs.

Data processed locally

Downly processes Chrome download records such as filenames, source URLs, final URLs, source domains, MIME types, file categories, file sizes, states, error codes, start times, end times, and progress values. It also processes your local settings and Smart Organizer rules.

downloads

Used to read Chrome download history, watch active downloads, calculate progress, search records, detect possible duplicates, and start repeat downloads when you choose that action.

downloads.open

Used only when you press an Open action for a completed download. Downly does not open files automatically.

downloads.ui

Used to apply the optional setting that replaces Chrome's native downloads UI with Downly. If the browser does not support the option, Downly shows a local warning.

storage

Used to save settings, theme preference, badge preference, filename conflict behavior, and Smart Organizer rules in local Chrome storage.

sidePanel

Used to show Downly in Chrome's side panel so you can inspect active and recent downloads without leaving the current tab.

No sale or sharing of data

Downly does not collect analytics, create accounts, sell data, share data with third parties, synchronize download history, or send files to external servers.

Local storage and clearing settings

Settings are stored under the local Chrome extension storage for this browser profile. To clear them, remove Downly from chrome://extensions, or open Chrome site and extension storage controls and clear the extension's local data. Clearing Chrome download history also removes the history records Downly can display.
