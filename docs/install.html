Install

Install Downly from source

Downly is version 0.1.0 and targets Chrome 123 or newer. Until a packaged release is published, load the built extension manually.

Chrome Web Store

Downly is not published in the Chrome Web Store yet. When it is published, this page will link to the listing and the install flow will be Chrome Web Store: open the listing, choose Add to Chrome, then approve the listed permissions.

Contributor install

  1. Install dependencies in extension/chrome.
  2. Run .
  3. Open chrome://extensions and turn on Developer mode.
  4. Choose Load unpacked and select extension/chrome/dist.
  5. Pin Downly or open the side panel to start managing downloads.

Packaging

After building, creates a zip artifact from the built extension.
