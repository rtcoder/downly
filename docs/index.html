Built around Chrome, not a cloud account

Private by design

Downly uses Chrome extension APIs to read and manage downloads inside your browser profile. Settings stay in local Chrome storage, and the extension does not upload history, URLs, filenames, or files.

FAQ

Common questions

Does Downly upload my download history?

No. Downly reads Chrome download records locally and stores settings in your browser profile.

Can it organize existing files?

Smart Organizer applies to downloads as Chrome determines their filename. Existing files and cleared history are not moved retroactively.

What happens if Chrome blocks a native UI setting?

Downly keeps working and shows a local warning. The side panel and manager remain available.

Downly is a local-first Chrome extension.
