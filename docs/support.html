Help with Downly

Downloads are not appearing

Click Refresh in the manager. Downly reads Chrome download history, so entries removed from Chrome history cannot be restored by the extension.

Smart Organizer did not route a file

Confirm that Smart Organizer is enabled, the rule is enabled, and the condition matches the download's source domain, filename, extension, MIME type, or category.

The native downloads UI was not replaced

Chrome controls support for downloads UI replacement. If your browser rejects it, Downly keeps working and reports the setting warning locally.

How to report an issue

Include your Chrome version, Downly version, operating system, the view you were using, and whether the problem involves search, actions, statistics, duplicates, or organizer rules. Do not include private file contents, full personal paths, secret URLs, tokens, or files themselves; redact filenames and domains when needed.
